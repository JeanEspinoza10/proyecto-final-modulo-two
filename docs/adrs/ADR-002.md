# ADR-002: Sistema de persistencia (H2 vs PostgreSQL)

## Estado
Aceptado

## Fecha
20226-05-15

## Contexto
La gestión bancaria requiere un sistema de persistencia confiable, seguro y escalable que garantice la integridad 
y disponibilidad de la información financiera.
Por ello, se evaluaron H2 como base de datos ligera para desarrollo y pruebas, 
y PostgreSQL como solución robusta para entornos productivos

## Decisión
Tomando como decisión según el contexto, se selecciona PostgreSQL como sistema de persistencia 
principal debido a su confiabilidad, soporte transaccional, escalabilidad y capacidad para manejar 
grandes volúmenes de información.
## Alternativas Consideradas
1. H2
2. PostgreSQL

## Consecuencias
### Positivas
- Integridad de los datos.
- Capacidad de manejar grander volúmenes de información. 

### Negativas
- Configuración y administración más compleja.
